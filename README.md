# 🛡️ Identificador de Mensagens de Golpes

Este projeto é parte de um *Challenge* (Desafio) da Residência Full-Stack 5.0.

## 🎯 O Desafio
O objetivo principal deste projeto é desenvolver uma solução que identifique mensagens características de golpes.

## 🛠️ Restrições Técnicas
*   A linguagem de programação utilizada deve ser Java.

## 📦 Entregáveis
*   Repositório no GitHub.
*   Um cenário de teste.
*   Ao menos uma regra de negócio implementada no programa.
*   Explicação da lógica e regra de negócio utilizada pelo grupo.

*Projeto desenvolvido por Monicke, Larissa e Mariana durante a Residência Full-Stack 5.0.*
